# Job Assistant - AI求职助手

一个基于 DeepSeek API 的智能求职辅助网站应用。

## 功能

1. **招聘简章分析** - 粘贴招聘信息，AI 分析企业看重的技能、背景要求和岗位职责
2. **个人成就分析** - 输入有成就感的事，AI 分析你的强项技能和兴趣
3. **简历投递建议** - 上传简历 + 目标岗位，AI 给出针对性建议

## 安装

```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的 DeepSeek API Key
```

## 运行

```bash
cd backend
python app.py
```

访问 http://localhost:5000
